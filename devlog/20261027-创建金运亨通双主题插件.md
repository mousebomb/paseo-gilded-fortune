# 2026-10-27 创建 Gilded Fortune（金运亨通）双主题插件

## 用户原始需求

做一个 Paseo 明暗双主题插件，与 `paseo-solarized` 并列开源。色源必须无第三方版权依赖。

最终方案：放弃「移植某个第三方 Obsidian 暗金主题」的路线（版权与命名都不干净，故不具名），
改用用户自建某页面（五行「补金」运势页）作为唯一色源，
暗端取原色、亮端由同一套色板推导。

定名：中文「金运亨通」，英文 `Gilded Fortune`；暗端金色选压一档（饱和度 65% → 55%）。

## 调研结论

- Paseo 官方目录（`getpaseo/plugins`，102 个主题条目）无金色档案风格同款；
  最接近的是 Golden Topaz（灰褐+青绿）、Cardstock（暖褐+红）、Claude Theme 的 Cocoa Night（可可+陶土橘）。
- 命名查重：Paseo 目录、npm、GitHub 均无 `gilded-fortune` 占用。

## 问题与取舍

1. **亮端强调金不能直接用源色**：`#d4af37` 在 `#f2ebda` 上约 1.9:1；即便 `#8a6d1f` 也只有 4.12:1，
   必须压到 `#7a5f1a`（5.08:1）才满足「强调底色上的文字取 background」的 4.5:1 要求。
2. **亮端 ring 无解冲突**：Paseo 0.13.2 打包产物里浅色 `surfaceSidebarSelected: t.surface4`（0.12.0 起回归），
   同一 token 还兼任 `foregroundExtraMuted` 与 composer placeholder。深了选中行糊，浅了弱化文字看不见。
   取中间调 `#8f7429`（两个用途各约 3.8:1），与 accent 同色相、同饱和度、只深两档，色系自洽。
   实测界面观感正常，用户确认「ring 的值看起来也很舒服」。
3. **暗端不受影响**：`surfaceSidebarSelected` 深色端走 `surface2`。
